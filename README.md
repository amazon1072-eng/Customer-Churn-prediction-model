Customer Churn Prediction Web App

A full-stack Machine Learning web application that predicts customer churn probability using an *XGBoost Pipeline* backend powered by *FastAPI* and a dynamic, responsive *HTML/JS* frontend.

---

## 📌 Features
* *Real-time Inference:* Fast predictions served via FastAPI REST endpoint.
* *Auto-calculated Metrics:* Automatically computes derived financial metrics on incoming inputs.
* *XGBoost Machine Learning Model:* Pre-trained model pipeline handling preprocessing and feature alignment.
* *Interactive Frontend:* Simple form interface with real-time churn status and percentage output.

---

## 🛠️ Tech Stack
* *Backend Framework:* FastAPI, Uvicorn, Pydantic
* *Machine Learning & Data Processing:* XGBoost, Scikit-Learn, Pandas, Joblib
* *Frontend:* HTML5, CSS3, JavaScript (Fetch API)
* *Deployment & Hosting:* GitHub, Render
